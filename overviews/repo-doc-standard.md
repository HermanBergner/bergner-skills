# repo-doc-standard

The platform's standard for how a repository documents itself — what goes where, how the pieces link together, and the conventions that keep docs findable and current across the `bergner-*` repos.

## When to use it

When setting up a new repo's documentation, or auditing an existing repo's docs for completeness and consistency.

## What you get

- A clear split: README vs. ARCHITECTURE/design docs vs. runbooks
- How those documents cross-reference each other
- Conventions that keep documentation discoverable and current
- A consistent shape so any `bergner-*` repo reads the same way
