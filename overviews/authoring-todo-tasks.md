# authoring-todo-tasks

The house manual for capturing work as well-formed tasks in the Bergner `todo` MCP — so anything you add is consistent, deduplicated, and properly linked instead of an ad-hoc note.

## When to use it

Any time work is being captured, drafted, or broken down for a bergner.no project — "add a task", "make tasks for X", "start a backlog", or any planning that ends in tracked work. Reach for it whenever you touch the `todo:` tools, even if no one says "skill".

## What you get

- Which tool sets which field, so nothing lands half-specified
- A search-first step that dedupes against existing tasks and wires up relations
- The right body for the audience — agent briefs versus human notes
- Conventions for task types vs. labels, priorities, sub-tasks, and bulk authoring
- A self-check that catches schema drift before it spreads
